# /halal page images

The page works fully with **zero photos** — every image area shows a tasteful
placeholder (a soft tone block naming the file) until you drop the real file in.
Add any of these and they light up automatically. Each spot is a **different
treatment**, on purpose.

| File                      | Treatment                              | Suggested shot |
|---------------------------|----------------------------------------|----------------|
| `scene-table.webp`        | **Full-bleed** banner (scrolls in, then the story continues) | A warm shared meal / Edmonton table |
| `label-closeup.webp`      | **Inset figure** inside the column, with caption | Close-up of a halal label / packaged meat |
| `mixed-grill.webp`        | **Side-by-side** (image beside the text, sticky) | A grill with mixed items / a menu |
| `community.webp`          | **Full-bleed** banner before the stats | Community / mosque / Edmonton crowd |

## Specs
- `.webp` preferred (smaller); `.jpg`/`.png` also work (keep the filename).
- Full-bleed shots: landscape, ~1920×1080, lower-detail reads best.
- Inset / side: ~1200×900 or 1000×1250 (portrait for the side-by-side).
- Keep each under ~300 KB for fast Cloudflare loads.

## Licensing
Only images you have rights to (your own, properly-licensed stock, or
AI-generated). **Do not** use CBC / competitor / news photos.
